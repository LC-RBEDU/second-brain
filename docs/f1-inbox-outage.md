# F1 — výpadek INBOX writerů (Sembly / Gmail / mobile)

Během F1 (po F1-e) jsou n8n INBOX writery **vypnuté**. Stale Slack INBOX je akceptováno do F3 (R26).

## Co nefunguje automaticky

- Sembly / Plaud → vault INBOX drop
- Gmail starred → INBOX
- Mobile capture → Drive vault

## Workaround

- Manuální zápis přes GitHub web UI PR (po F1-h), nebo počkat na F2/F3.
- Urgentní reminder: Slack reminder bot / ruční DM (ne `schedule_reminder` na git klonu).

## Po F1-h

Jediný automatický vault writer = Coolify hub (deploy key → `main`).
